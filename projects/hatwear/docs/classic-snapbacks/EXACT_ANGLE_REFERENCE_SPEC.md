# Exact angle reference spec

User-approved angle definitions:

## 1. Front
Reference file: `reference/FRONT_VIEW_exact_reference.png`
- three-quarter front product view
- front logo clearly visible
- brim visible
- not a perfectly flat straight-on shot

## 2. Back
Reference file: `reference/BACK_VIEW_exact_reference.jpg`
- straight rear view
- opening and snap strap centered
- no front brim visible

## 3. Inside / Underside
- underside of brim + interior headband / inside view

## 4. Side
- right-side profile view
- side embroidery visible when present

All four should be separate assets and separate boxes in the UI.
