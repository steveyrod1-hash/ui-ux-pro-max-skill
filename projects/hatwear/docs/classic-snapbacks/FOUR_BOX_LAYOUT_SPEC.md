# Four-box image layout spec

For each hat, the website should preserve four **separate** image assets and show them in four clearly divided boxes.

## Required order
1. Front
2. Back
3. Inside / Underside
4. Side

## Recommended layout
- Desktop: 2 columns × 2 rows
- Mobile: 1 column × 4 rows or 2 × 2 if space allows
- Each box should have:
  - a visible label
  - square image area
  - fallback placeholder if the image is missing

## Do not
- collapse the four views into one permanent flattened image
- show the wrong hat or wrong angle in a box
- use one team's photo as a placeholder for another team

## Exact BACK image requirement (user correction)

Use `reference/BACK_VIEW_EXACT_REFERENCE.jpeg` as the authoritative reference **for the camera viewpoint**, not as a substitute photo for other teams. The back view must be:
- **Straight-on from directly behind** the hat, centered and symmetrical, not a 3/4 rear view or side view.
- Entire rear crown visible, including rear seam, ventilation eyelets, the rear cutout/opening, and **adjustable snapback strap across the lower center**.
- Brim should face away from the camera, so it is not visible projecting to either side.
- Plain clean background, whole hat in frame, similar scale/crop across all products.
- Use the actual corresponding hat's rear photo; if missing, a labeled placeholder is better than a fabricated angle.
